### Graph Visualiser

Graph Visualiser is a program written in C using Raylib to play with graphs.
You can perform such things as changing Matrix of Contiguity, deleting/adding knots, hot-randomizing the graph itself. And... That's pretty much it for now.

# In the application

F5 - randomize graph
G - open/close menu
E - add knot(if you're holding a knot it will add knot near the knot you're holding and link it, if not - randomized position)
Q - delete knot(if you're holding a knot, deletes the knot you were holding, if not - the last one)

# Menu

Matrix of contiguity - you can change links by clicking on needed cells
+/- buttons - add a knot/delete the last one
